# CSAT Campaign Builder

A responsive React-based CSAT (Customer Satisfaction) Campaign Builder that allows users to configure campaign content, customize styling, and preview the campaign in real time through a mobile interface.

## Features

- Real-time mobile campaign preview
- Controlled React components
- Initial Feedback configuration
- Feedback question customization
- Star and number rating styles
- Dynamic feedback option management
- Add and delete feedback options
- Additional comments toggle
- Thank You page customization
- Thank You media upload
- Custom colors and typography
- Button customization
- Popup styling
- Responsive design
- Reset campaign functionality

## Tech Stack

- React.js
- JavaScript
- CSS
- Vite
